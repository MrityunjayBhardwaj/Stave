## What Stave is

Stave is a studio built around your [Strudel](https://strudel.cc) code. You write the song as code, and Stave gives it the views a music producer expects: a **Timeline** for the whole song, a **Pattern** grid for the line you're on, a **Mixer** for every track, and **visuals** that react to every note.

It works both ways. Pull a fader and the `.gain` in your code changes. Click a step on the grid and the beat in your code changes. Type a new note and the grid redraws. Your code is always the song.

Everything runs in your browser. Projects are stored there too. A share link opens a locked copy whose key is only in the link.
