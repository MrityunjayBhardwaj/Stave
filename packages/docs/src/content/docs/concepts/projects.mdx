A Stave **project** is a set of files and folders, your audio, and a layout. Everything is saved in your browser. There's no account and no server.

## File kinds

| Extension | What it is |
|---|---|
| `.strudel` | A Strudel song or pattern. This is what plays. |
| `.p5` | A p5.js sketch, also usable as a named visual |
| `.hydra` | A Hydra sketch, also usable as a named visual |
| `.glsl` | A GLSL shader in the ShaderToy style, also usable as a named visual |
| `.sonicpi` | Sonic Pi code. It opens with highlighting but [doesn't play in this build yet](/runtimes/sonicpi/). |
| `.md` | Notes |

Visual files (`.p5`, `.hydra`, `.glsl`) open as their own tab, and they can also be used by name from `.viz("…")` in a Strudel file. A new visual file starts with a short sketch that already reacts to the music.

Make a file with the **New file** button in the Files panel or the **+** at the end of the tab bar. Include the extension in the name. Two files in one folder can't share a name.

## The Files panel

- Drag files and folders to reorder them, or onto a folder to move them there.
- **⌘Z** undoes a move or a reorder.
- Drop a file from your desktop onto the panel to bring it in.
- **Duplicate** makes "copy", then "copy 2", and so on.

## Version History

Open it from **File › Version History…** or the history icon in the activity bar.

- Stave saves a version on its own a few seconds after you stop typing.
- The panel shows the project's history as a graph. Each version can be **Restored**, **Forked** into a new project, or **Viewed**, and you can open a diff of any file.
- To see one file's history, right-click it in the Files panel and choose **File History**.

## Share links

**File › Copy Share Link** puts the whole project into a link like `https://stave.live/#share=…`. Whoever opens it is asked "Import shared project?".

- The project lives in the part of the link after `#`, which browsers never send to a server.
- A share link carries your files, not your audio. To send audio as well, export a `.zip`.
- A project too big for a link (over 2 MB before compression) asks you to export a `.zip` instead.

## Import and export

- **File › Export as .zip** saves every file and folder, plus the audio you recorded or brought in.
- **File › Import from .zip…** opens one. You can also open an archive from the start screen.
