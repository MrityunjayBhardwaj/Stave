# Getting help

Thanks for using Stave. Here's where each kind of question goes.

## How do I…?

Start with the [docs](https://stave.live/docs/). They cover getting started, the Timeline, the Pattern grids, the Mixer, and writing visuals in p5.js, Hydra and GLSL.

If the docs don't answer it, ask in [Discussions](https://github.com/MrityunjayBhardwaj/Stave/discussions). That's the place for questions, ideas, and songs or sketches you'd like to show. Other people can find the answer there later, too.

## Something's broken

[Open an issue](https://github.com/MrityunjayBhardwaj/Stave/issues/new/choose) with the "Something's broken" form. The most useful things to include are the code you were playing, what you expected, what happened instead, and your browser.

## I have an idea for Stave

Small, concrete ideas fit the "An idea" issue form. For bigger or rougher ones, start a thread in [Discussions](https://github.com/MrityunjayBhardwaj/Stave/discussions) first. The [roadmap](https://stave.live/docs/roadmap/) shows what's already planned.

## I found a security problem

Please don't post it publicly. The [security policy](SECURITY.md) explains how to report it privately.
